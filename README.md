# მეკა ჟურნალი

ვებგვერდი **შპს მეკასთვის**. WhatsApp ჯგუფის „შპს მეკა ყოველდღიური ფოტომასალა“ ექსპორტიდან ქმნის ყოველდღიურ ჟურნალს: ფოტოებით, ძიებით, WhatsApp-ში გაზიარებით და Excel-ში ჩამოტვირთვით.

## როგორ მუშაობს
1. WhatsApp-ში ჯგუფიდან აკეთებ „Export chat“-ს (მედიით) და იღებ zip ფაილს.
2. ატვირთავ zip-ს გვერდზე. გვერდი ტექსტს დღეების მიხედვით ალაგებს და ფოტოებს ინახავს. ერთხელ უკვე ჩაწერილი შეტყობინებები მეორედ არ ემატება.
3. შეგიძლია ძებნა, თარიღით გაფილტვრა, Excel-ში ჩამოტვირთვა და WhatsApp-ში გაზიარება.

## გაშვება კომპიუტერზე
```
npm install
npm run dev       # http://localhost:5173
npm test          # ჩატის წამკითხველის ტესტები
npm run sample    # ქმნის სატესტო zip-ს samples/ საქაღალდეში
```

## საერთო ონლაინ ვერსია (Supabase + Vercel)
1. შექმენი Supabase პროექტი და SQL Editor-ში გაუშვი `supabase/schema.sql`.
2. Authentication-ში გამორთე თვითრეგისტრაცია და მომხმარებლები ხელით დაამატე.
3. დააკოპირე `.env.example` ფაილი სახელით `.env` და შეავსე Project URL და anon key.
4. `npm run build`, შემდეგ `dist/` საქაღალდე ატვირთე Vercel-ზე.

თუ `.env` ცარიელია, გვერდი მონაცემებს მხოლოდ ბრაუზერში ინახავს.

## სტრუქტურა
- `src/parser.js`: კითხულობს WhatsApp-ის ექსპორტს (Android და iPhone)
- `src/importer.js`: ხსნის zip-ს, ამცირებს ფოტოებს და ინახავს მხოლოდ ახალ შეტყობინებებს
- `src/db-local.js` / `src/db-remote.js`: ინახავს მონაცემებს ბრაუზერში ან Supabase-ში
- `src/share.js`, `src/excel.js`: WhatsApp-ში გაზიარება და Excel
- `.claude/think-it-through/site-app.md`: პროექტის გეგმა
